# Code of Conduct

bootstrapcn welcomes contributors with different backgrounds, experience levels and perspectives. Participation in issues, pull requests and discussions requires respectful behavior.

## Expected behavior

- Be considerate, patient and constructive.
- Focus feedback on the work and explain your reasoning.
- Respect others' time, privacy and boundaries.
- Assume good intent while accepting corrections and taking responsibility for mistakes.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, personal attacks, persistent disruption and publishing another person's private information are not welcome. These rules apply in project spaces and when representing the project elsewhere.

## Reporting and enforcement

Report concerns privately to the repository owner, [soumit101](https://github.com/soumit101), using an available private contact method on their GitHub profile. Avoid posting private information or incident details in public issues. If no private contact is available, ask the maintainer for one without sharing sensitive details.

Maintainers may edit or remove content, close discussions, warn participants, temporarily restrict participation or permanently ban repeated or serious violations. Decisions should consider the impact and severity of the behavior. Maintainers must follow these standards too.
